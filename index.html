Posteria No longer actively developed

Posteria has been replaced by Marquee

Thanks to everyone who used Posteria. It is no longer being actively developed, and new features and fixes are not planned.

Everything Posteria did has been rebuilt from the ground up in Marquee — a complete re-write that is faster, easier to run, and actively maintained.

Meet Marquee

Self-hosted poster management for Plex™ — the successor to Posteria, and where all development continues.

  • Import posters straight from Plex
  • Movies, TV shows, seasons, and collections
  • Built-in poster search, upload, or a URL
  • Sync back to Plex and lock your artwork
  • Scheduled auto-import keeps things current
  • Poster Wall for a spare screen
  • Mobile friendly and installable as a PWA
  • Free and open source
Get Marquee Marquee on GitHub

The Find Poster API stays here

The Find Poster API is not moving to Marquee. It remains on the posteria.app domain and is actively maintained.

The legacy API is not. It still runs, but like Posteria itself it is unmaintained — no new features, fixes, or support.

Still running Posteria?

Posteria remains open source and the existing Docker image still works, but it is unmaintained — no new features, fixes, or support. Switching to Marquee is strongly recommended.
